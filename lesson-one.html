Lesson 1: Introduction to User Interface Design


User Interface Design is the planning and creation of a set of controls that enables a user to interact with a computer device

Goal: make the interaction between human user and computer device simple, effecient, effective, and enjoyable.

Intro to UI Design

6 principles of good UI design:

  • Structure: clearly understandable at a glance
    • site map with clear navigation
  • Simplicity: self-explanatory; easy to use; unadorned layouts, images, and colors
  • Visibility: easy on the eyes, legible text, each page has a clear purpose, straightforward, predictable, clear metaphors
  • Feedback: timeliness when an input is accepted, when an error has occured, when the site is still working
  • Tolerance: high level of tolerance minimize errors, easily undo or redo actions when an error does occur
  • Reuse: make aspects reusable to maintain consistency, reduce the need to rely on thought and memory

design trends:

  • Mobile Devices: designing for mobile is now the rule, must be able to work on all devices
  • Flat Design: simple navigation, plenty of white space, large and bold images and fonts, single color dominance
  • Data Visualization: depicting complex data in simple visual form
  • Scrolling Trends: Parallax scrolling (when background and foreground scroll at different rates depending on how fast the user is scrolling), long-page scrolling
  • Human look & feel: hand drawn elements, stories

Evolution of Web User Interfaces

MIT professor J.C.R. Licklider researched into a "Galactic Networ" in the 60s that would foster social interaction betwen users. In the early 60s, UCLA and a few other universities fostered the creation ofARPAnet, the Advanced Research Project Agency (ARPA) network. ARPAnet then fostered the creation of the Internet, which was officially born in 1982 with the standardiszation of the Transmission Control Protocol/Internet Protocol (TCP/IP), a suite of protocols for sending and receiving messages over the Internet.

In 1989, Tim Berners-Lee, a British computer scientist and employee of the European Organization for Nuclear Research (CERN), wrote a proposal for a more effective communication system for CERN, which he realized could be implemented globally. In 1990, he and a Robert Cailliau, a Belgian computer scientist, proposed the use of the hypertext "to link and access information of various kinds as a Web of nodes in which the user can browse at free will."

The World Wide Web was born: a system of interlinked hypertext documents that reside on the Internet and can be accessed via Web browsers.

Note:The Internet is a massive network of networks that connets millions of computers across the globe. The World Wide Web is a vast library of hypertext documents (Web pages) that are stored on the Internet and viewed in Web browsers

The first Web site

August 1991 Tim Berners-Lee published the first site for the World Wide Web

Early HTML elements

The earliest versions of Hypertext Markup Language (HTML) suported only a few basic Web site elements:

  • headings (<h1>,<h2>, etc.)
  • paragraphs (<p>)
  • links (<a>)

they were very s imple, single-comlumn, text only, standard fonts, underlined links. Later images (<img>) also came along.

Type-based layouts

HTML <table> element was created to display tabular, spreadsheet-like data. But designers realized that could be used to lay out their page content. Multi-column layout became common. Now, they are rarely used for layout, w. CSS3 being used instead.

Flash

tables began to be to complicated and bulky, so Macromedia, Inc. introduced Flash technology, which started in 1996. It enabled designers to overcome severe limitations of HTML. It became possible to create sites with interactive animations. But there were downsides:

  • it required the plug-in, which every user might not have, or have up-to-date
  • Flash-heavy pages took too long to load and often had confusing navigation.
  • Flash is a closed system, controlled by one company (now Adobe), vs standard Web languages, which are open-source technologies. Project developnent was hampered by slow responses to improving the software.
  • Flash amassed a history of weak security and for crashing Macs, which resulted in Apple's discontinued support of Flash on Apple products in 2010

Dynamic HTML (DHTML)

This was beginning to be used around the same time as Flash was emerging. DHTML is an umbrella term for a set of technologies used to create interactive Web sites, typically HTML, JavaScript, and CSS. With this and Flash, the notion of interactive webpages was introduced. However DHTML continues to be used because the technologies on which it's based are standard open-sourced technologies that do not require any special software or plug-ins to develop or use.

  • HTML5 (current version of HTML)
    Being so sophisticated, it was also responsible for the decline of Flash. It, with CSS and JavaScript can do anything Flash can well, or better.
  • Cascading Style Sheets (CSS) (current standard is CSS version 3 (css3))
    technology specifies the appearance of the HTML documents (web pages). It is very flexible and powerful, enabling a single page to lay out or design for a whole site.

Current Trends in Web Design

Mobile is the rule, not the exception

You no longer can design for desktop, and tweak later for mobile. You need to think mobile from the beginning.

Responsive design is required

this is typically accomplished using fluid page grids, flexible images, and CSS3 media queries

Less is more

Flat UI objects, simple navigation,a dn plenty of white space are all desireable in current interfaces

Think BIG!

large, bold images and fonts are currently in style.

Data visualization

depicting data in simple visual form

Parallax

background crolls slower than foreground, creating an illusion of 3-D depth and movement

One-color dominance

an extension of the flat UI trend

Long-scrolling pages

designer used to want to keep the content as much "above the fold" as possible, now it's the opposite

Human look and feel

hand drawn images, non-rectangular layouts, etc.

Storytelling

more engaging to users
